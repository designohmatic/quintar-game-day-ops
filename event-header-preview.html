What changed
1
Back button (new)

30×30 chip on the far left, returns to / (the landing). Quiet by default, blue on hover. Makes the multi-session model legible — you're inside an event, not at the app.

2
Event name + status pill (new)

Replaces the static EVENT badge from the prototype. Shows which event you're inside and its lifecycle state (Setup → Live → Complete). The Live pill pulses green, mirroring the existing GO LIVE top-bar treatment.

3
Participants present (new)

Stacked avatars of users currently in this Socket.IO room, with a "+N" overflow. Shows live presence — who else is looking at this checklist right now. Click would open a small roster popover (later).

4
Elapsed timer + Progress pill (preserved)

Same components as today's prototype. Elapsed is still the time since the event was created. Progress pill still shows percentage complete and step count. No visual change.

What did NOT change
✓
Everything below the header

Phase progress pips (sticky), step cards, long-press flyouts, escalation ladder, note forms, auto-advance chain, undo cascade, step timers, issue duration tracking, Resolved action, Stream Live banner, time report, CSV export, all brand tokens, all interaction handlers — untouched.

✓
Phase pips + GO LIVE state

The sticky phase progress bar remains directly below this header. The GO LIVE pip still lights green when all steps complete. The state pill in the top-right header is a redundant cue, not a replacement.
